**Confound, stated plainly:** top-1 counts a gate-silent as a miss, and the battery runs
Jev's shipped `gate 0.30`. Models whose gate scale sits below Jev's never reach Call-2
(`calls=1` rows) and are punished for a threshold mismatch, not for picking badly —
shortlist recall stays 88% for every model, which is the selection-quality signal.
`mercury-decide` is the one candidate whose scale matches Jev, so its 75% is directly
comparable. The rest would need their own gate before their true top-1 is known — that
work is not justified while a drop-in tie exists.

## 4. Adoption decision

## 5. Harness note

`solar_probe.py` loaded the **installed** plugin (`~/.hermes/plugins/jev-suggest/__init__.py`)
by hardcoded path, so a run from a checkout measured the install — and an unallowlisted slug
would have silently fallen back to the default model while wearing the candidate's name. The
path is now overridable via `JEV_SUGGEST_PLUGIN` (default unchanged), and the intake script
points it at its own checkout and asserts every slug is in the loaded module's allowlist.
